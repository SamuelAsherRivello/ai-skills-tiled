# Tiled AI Skills

MCP-backed workflows for editing an open [Tiled](https://www.mapeditor.org/)
project through the verified `rpgjs/tiled-ai` bridge. Run setup before any
authoring skill; it verifies the local bridge, extension, Codex MCP entry, and
live editor connection.

- [Tiled AI Setup](../skills/tiled-ai-setup/SKILL.md): Set up and verify the Tiled AI
  bridge before map edits.
- [Tiled AI Add Sample Level](../skills/tiled-ai-add-sample-level/SKILL.md): Create a
  layered floor, walls, and objects sample map from one tileset.
- [Tiled AI Add Tileset Autotiling](../skills/tiled-ai-add-tileset-autotiling/SKILL.md):
  Add and visually verify Wang terrain metadata on an existing tileset.
- [Tiled AI Add Tileset Automapping](../skills/tiled-ai-add-tileset-automapping/SKILL.md):
  Author and verify map-scoped Automapping rules for an existing tileset.
- [Tiled AI Add Character](../skills/tiled-ai-add-character/SKILL.md): Add an animated
  character with Tiled AI placement data and runtime integration.
- [Tiled AI Add Object](../skills/tiled-ai-add-object/SKILL.md): Add a tested,
  independently placeable object through Tiled AI.
- [Tiled AI Add Pickup Object](../skills/tiled-ai-add-pickup-object/SKILL.md): Add a
  pickup object and its reusable runtime path.
- [Tiled AI Add Spawner](../skills/tiled-ai-add-spawner/SKILL.md): Add map-authored
  actor spawners through the live editor.
- [Tiled AI Add Tileset](../skills/tiled-ai-add-tileset/SKILL.md): Convert tile-sheet
  art into an inspected external tileset.
- [Tiled AI Copy Tileset Colliders](../skills/tiled-ai-copy-tileset-colliders/SKILL.md):
  Copy verified collider geometry with the live editor.
- [Tiled AI Update Tileset Colliders](../skills/tiled-ai-update-tileset-colliders/SKILL.md):
  Inspect and update existing collider shapes through Tiled AI.
