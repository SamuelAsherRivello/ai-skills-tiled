# References

The [Tiled AI MCP editing contract](references/tiled-ai-mcp.md) records the shared rules for editor revisions, targeted changes, visual inspection, and saving. Skills that depend on it include a local copy under their own `references/` directory so they remain usable when installed alone.

The bridge's API and installation instructions belong to [rpgjs/tiled-ai](https://github.com/rpgjs/tiled-ai). Consult its current documentation for supported MCP tools.
