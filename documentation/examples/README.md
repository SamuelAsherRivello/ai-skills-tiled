# Examples

[Browse the Wang gallery](../examples-readme.md) for prompts, tileset PNGs, and sample level PNGs. Each numbered example contains a portable TMX map and its external TSX beside the tile image.

The [Starter Map](starter-map/README.md) is a portable Tiled example with a TMX map, external TSX tileset, and local tile image. It demonstrates the asset layout the skills ask users to verify when sharing a map.

The [Figure 8 Autotiling](figure-8-autotiling/README.md) example shows two joined rooms and an unwalkable core. Its external TSX contains a mixed Wang set for the 21 masks used by this footprint, and its preview shows the generated map.

An example file is evidence of format and packaging. It does not imply a live MCP session was used to create it.
